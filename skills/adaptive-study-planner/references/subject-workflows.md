# 各科怎样形成完整任务

下面的分钟数、题数是初次估算示例，必须根据实际材料和反馈修改。不能直接当成每日配额。每次只读取/使用本次涉及的科目。

## 高数：输入、示例、独立解题、订正

1. 从本节先修知识抽少量代表题/口头条件检查；会的跳过重看，不会的定位到具体概念。
2. 视频按一个可应用的概念或例题单元切分。暂停时先预测下一步，再看老师解释；不用每分钟暂停，也不用抄整段讲稿。
3. 新手先理解完整示例，再尝试补关键步骤，随后闭卷独立做同类基础题。掌握基本方法后加入需选择方法的混合题或小变式，避免尚未学会就随机混入大量难题。
4. 检查答案和过程：适用条件、方法选择、计算、审题、书写。订正后遮住解析重做关键部分；“刚看完能复现”记作当次纠正，延迟独立完成才是更强掌握证据。

示例60分钟卡：5分钟先修检索 + 20分钟视频/示例（已含暂停）+ 25分钟独立题 + 10分钟反馈。若原视频本身就有40分钟，应切成一段或扩大可用窗口，不把暂停、做题塞进不存在的时间。最低标准可以是：能说出方法条件，独立完成覆盖核心题型的2道代表题，完成已尝试题反馈并标出未解决点；题数随本节结构改变。未满足独立性则标“任务已停止、掌握未达标”。

配套题少：先检查是否覆盖核心变化。若只重复一个套路，可从已知教材/题库选变式，或让助手生成少量明确标注“自编、非真题”的题，并核验解答；没有可靠答案时保留待验证，不把自己对自己打分当证据。已经覆盖且独立通过，就休息或进入下一张队列，不为凑时长找题。

## 计算机：先确定考试形式

不要将“计算机”自动等同于编程。课程/考纲未知时保留分支，先用用户实际课程内容。

| 类型 | 输入后必须做的输出 | 反馈与完成判断 |
|---|---|---|
| 基础知识、网络、系统等理论 | 闭卷回答小问题、比较易混概念、做相关题 | 解释答案与错选原因；不能只靠选择题眼熟 |
| Office等操作 | 看一段演示后自己从起点操作、保存结果 | 按目标效果/步骤要求检查；无操作环境则标实操待完成 |
| 算法、程序阅读 | 手算/跟踪变量、解释边界条件、做题 | 对照结果及中间状态，定位逻辑错误 |
| 考试确实涉及编程 | 独立实现小功能、运行代表性输入 | 检查预期输出、边界与错误处理；无运行条件不得声称测试通过 |

示例60分钟：20分钟视频（含暂停）+ 5分钟闭卷结构回忆 + 25分钟对应题/操作 + 10分钟检查。基础熟练时减少视频，把预算转向应用；新概念多则缩小内容单位，不固定视频刷题比例。

## 英语词汇：到期旧词与新词分别计时

先看软件到期量或本地记录，旧词按需求做词形→义、语境辨义；考试/输出需要时再加入中文/情境→英文及拼写。一次卡片聚焦一个检索目标，错词看语境与搭配后再回忆，不让大量复制笔记占用预算。

示例25分钟：15分钟到期词检索与反馈 + 8分钟少量新词的发音、常见义及例句 + 2分钟登记难词。15分钟到点仍有旧词时先按风险分批；必要时取消今天8分钟新增并用于高优先旧词，仍需保留记录时间。旧词清空且状态良好也不自动翻倍新词，考虑未来复习容量。

新词量用最近真实的每词学习耗时与后续复习负担估算，不承诺每天固定100词。“眼熟”与“无需选项能提取”分开记录；当天答对不代表永远掌握。

## 英语语法与阅读：做题和分析是两笔预算

语法：短诊断→缺口讲解→闭卷做题→解释关键结构与错因→延迟再测。已熟练部分直接练习；不为了主动练习让完全陌生语法硬猜。

阅读：按当前基础决定训练模式。计时模式参考目标考试或用户给定要求；初学精读可先不限时并记录耗时，不虚构官方每篇分钟数。

示例45分钟阅读卡：18分钟独立完成一篇 + 22分钟反馈（定位原文证据、解释干扰项、拆关键难句）+ 5分钟记录下次检索点。文章很长则降低篇数/切任务，不能做三篇却不给分析时间。生词优先处理影响理解或反复出现者，不逐词抄全篇。对已答对题抽查理由，以识别猜对。

只做完题没有分析完：状态写“答题完成、分析待续”；记录剩余题号、证据定位点。续接卡先分析这些内容，再决定是否开下一篇。

## 英语口语与日语

口语：短示范→脱稿回答→录音/自查或外部反馈→选少量问题修正→再次脱稿。示例20分钟可分3+7+5+5；录音不是默认必需，有环境限制可口述。不能把背稿时长等同于临场表达能力，也不替代专升本阅读/语法任务。

日语跟课期按实际课程作业与检索安排；维持期只选用户接受的任务；暂停期不生成每日最低量。重新启动先短诊断，再从实际保留程度恢复，不能默认失去全部旧知识。
