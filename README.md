# 动态学习调度 Skill

面向高数、专升本英语和计算机备考的中文 Skill。支持视频学习、独立练习、反馈订正、跨天复习以及课程阶段变化。每天的时段可以变，任务的验收与续接规则保持清楚。

## 它会处理什么

- 数学、计算机：讲解与做题配套，按基础选择示例和独立练习。
- 英语：词汇新学与到期复习分开，阅读/语法做题留出分析时间，口语单独计入。
- 提前完成：验收后决定休息、复习或推进下一任务，不要求凑满时间。
- 超时：保留反馈，记录具体断点，迁移到下个合适窗口并重新计算后续计划。
- 精力下降或任务积压：缩减新增与扩展内容，保护固定活动和停止学习边界。
- 阶段变化：用当前课程、考试和个人偏好决定是否跟课、加强主科或暂停副线。

## 使用

技能入口是 [`skills/adaptive-study-planner/SKILL.md`](skills/adaptive-study-planner/SKILL.md)。将整个 `adaptive-study-planner` 技能文件夹放入支持 `SKILL.md` 的助手的技能目录；Codex 的个人技能目录通常为 `$CODEX_HOME/skills`，未设置时为 `~/.codex/skills`。是否加载成功以宿主技能列表为准。

示例请求：

> 使用 $adaptive-study-planner。我明天只有下午两小时和晚上一个半小时，高数正在学极限，计算机有一节视频，英语有到期单词。先排核心任务，写清做快或做慢后怎么办。

> 数学原计划一小时，三十分钟做完了，答案都核对了，现在有点累。下一步是什么？

> 阅读到时间还没分析完，晚饭不能推迟，帮我续接剩下任务。

首次使用提供已知日程、材料与进度即可；缺少题量时会先估算并在执行后校准，不虚构题号或考纲。

## 个人配置与进度

可在技能文件夹内创建 `profile.local.md` 保存个人目标和有效期，创建 `state.local.md` 保存执行记录，格式见 [记录说明](skills/adaptive-study-planner/references/state-format.md)。这些文件被本仓库 `.gitignore` 排除，公开版本不含个人聊天、具体课表或健康记录。不要强制加入这些本地文件。

技能依赖用户报告完成情况；不会自行计时、发提醒或把新聊天与旧聊天的记录自动同步。

## 学习依据

采用检索练习、间隔学习及示例与独立练习结合等原则；具体分钟数、缓冲比例、复习间隔是可校准的工作参数。来源、借鉴范围与局限见 [依据与限制](skills/adaptive-study-planner/references/evidence.md)，实际分支见 [场景示例](skills/adaptive-study-planner/references/scenarios.md)。
